# Ripasso: Notazione degli intervalli

Per scrivere correttamente il **dominio** di una funzione è fondamentale saper passare con sicurezza dalla forma con disuguaglianze alla **notazione per intervalli**. In questa pagina trovi un ripasso visuale dei casi principali, con figure generate automaticamente da Python tramite celle eseguibili di Jupyter Book.[1][2]

:::{note}
Regola di base:
- si usano le **parentesi quadre** quando l'estremo è incluso;
- si usano le **parentesi tonde** quando l'estremo è escluso;
- con $$+\infty$$ e $$-\infty$$ si usano **sempre** le parentesi tonde.
:::

```{code-cell} python3
:tags: ["remove-cell"]

import matplotlib.pyplot as plt

plt.rcParams["font.family"] = "serif"
plt.rcParams["mathtext.fontset"] = "stix"

def draw_interval(
    left_closed=True,
    right_closed=True,
    left_infinite=False,
    right_infinite=False,
    color="#2980B9",
    label=r"[a,b]",
    inequality=r"a \leq x \leq b"
):
    fig, ax = plt.subplots(figsize=(6.0, 1.65))

    xmin, xmax = 0, 10
    y = 0
    a, b = 3.2, 7.1

    # Asse tratteggiato con freccia nera a destra
    ax.plot([xmin + 0.8, xmax - 0.9], [y, y],
            linestyle=(0, (3, 3)), color="black", linewidth=1.1, alpha=0.75)
    ax.annotate(
        "",
        xy=(xmax - 0.45, y),
        xytext=(xmax - 1.05, y),
        arrowprops=dict(arrowstyle="->", color="black", lw=1.1)
    )

    # Segmento colorato
    start = xmin + 1.0 if left_infinite else a
    end = xmax - 1.0 if right_infinite else b
    ax.plot([start, end], [y, y], color=color, linewidth=2.4, solid_capstyle="round", zorder=3)

    # Freccia verso -infinito
    if left_infinite:
        ax.annotate(
            "",
            xy=(xmin + 0.35, y),
            xytext=(xmin + 1.0, y),
            arrowprops=dict(arrowstyle="->", color=color, lw=2.4)
        )

    # Freccia verso +infinito
    if right_infinite:
        ax.annotate(
            "",
            xy=(xmax - 0.35, y),
            xytext=(xmax - 1.0, y),
            arrowprops=dict(arrowstyle="->", color=color, lw=2.4)
        )

    # Estremo sinistro
    if not left_infinite:
        ax.plot(
            a, y,
            marker="o",
            markersize=5.6,
            markeredgewidth=1.4,
            markeredgecolor=color,
            markerfacecolor=color if left_closed else "white",
            zorder=5
        )
        ax.text(a, y + 0.18, r"$a$", ha="center", va="bottom", fontsize=12.5, color=color)

    # Estremo destro
    if not right_infinite:
        ax.plot(
            b, y,
            marker="o",
            markersize=5.6,
            markeredgewidth=1.4,
            markeredgecolor=color,
            markerfacecolor=color if right_closed else "white",
            zorder=5
        )
        ax.text(b, y + 0.18, r"$b$", ha="center", va="bottom", fontsize=12.5, color=color)

    # Etichetta a sinistra
    ax.text(1.0, 0.03, f"${label}$", ha="left", va="center", fontsize=15, color=color)

    # Disuguaglianza sotto
    mid = (a + b) / 2 if (not left_infinite and not right_infinite) else 5.2
    ax.text(mid, y - 0.35, f"${inequality}$", ha="center", va="center", fontsize=15, color=color)

    ax.set_xlim(xmin, xmax)
    ax.set_ylim(-0.62, 0.55)
    ax.axis("off")
    plt.tight_layout()
    plt.show()
```

## Intervalli limitati

Gli intervalli limitati sono compresi tra due numeri reali finiti, che qui indichiamo con $$a$$ e $$b$$, con $$a<b$$.

## Intervalli illimitati

Quando uno dei due estremi è infinito, l'intervallo diventa una semiretta. In questi casi l'infinito non è mai un estremo incluso, quindi compare sempre con parentesi tonda.

:::{warning}
Errore tipico da evitare: scrivere $$[a,+\infty]$$ oppure $$[-\infty,b]$$. L'infinito non può mai essere “chiuso”.
:::

::::{grid} 1 1 2 2
:::{grid-item-card} **INTERVALLO CHIUSO ILLIMITATO**
```{code-cell} python3
:tags: ["remove-input"]

draw_interval(
    left_closed=True,
    right_infinite=True,
    color="#1f77b4",
    label=r"[a,+\infty)",
    inequality=r"x \geq a"
)
```
:::

:::{grid-item-card} **INTERVALLO CHIUSO ILLIMITATO**
```{code-cell} python3
:tags: ["remove-input"]

draw_interval(
    right_closed=True,
    left_infinite=True,
    color="#1f9d55",
    label=r"(-\infty,b]",
    inequality=r"x \leq b"
)
```
:::

:::{grid-item-card} **INTERVALLO APERTO ILLIMITATO**

## Esempi illustrativi

### Da disuguaglianze a intervalli

- $$x< -4$$ diventa $$( -\infty, -4 )$$.
- $$-3 \leq x < 5$$ diventa $$[ -3, 5 )$$.
- $$x \leq 0 \lor x > 7$$ diventa $$( -\infty, 0 ] \cup ( 7, +\infty )$$.

:::{dropdown} Soluzioni commentate
1. In $$x< -4$$ il valore $$-4$$ è escluso, quindi si usa la parentesi tonda; a sinistra compare $$-\infty$$, anch'esso sempre con parentesi tonda.
2. In $$-3 \leq x < 5$$ il $$-3$$ è incluso e il $$5$$ è escluso, quindi si ottiene $$[ -3, 5 )$$.
3. La scrittura con $$\lor$$ indica due insiemi distinti, quindi la soluzione va espressa come unione di due intervalli.
:::

### Da intervalli a disuguaglianze

- $$[ -2, 8 ]$$ diventa $$-2 \leq x \leq 8$$.
- $$( -\infty, 4 ) \cup [ 10, +\infty )$$ diventa $$x<4 \lor x \geq 10$$.
- $$\mathbb{R}\setminus\{3\}$$ equivale a $$( -\infty, 3 ) \cup ( 3, +\infty )$$, cioè $$x \neq 3$$.

:::{dropdown} Osservazione utile
Quando l'insieme soluzione contiene “tutti i reali tranne un punto”, spesso la forma più compatta non è quella con gli intervalli ma una semplice condizione del tipo $$x \neq c$$.
:::

## Esercizi svolti

### Esercizio 1
Tradurre in notazione per intervalli:

1. $$x \geq 2$$
2. $$-1 < x \leq 6$$
3. $$x < -3 \lor x \geq 4$$

:::{dropdown} Svolgimento
1. $$x \geq 2$$ significa tutti i valori da 2 in poi, incluso il 2: $$[2,+\infty)$$.
2. $$-1 < x \leq 6$$ significa estremo sinistro escluso ed estremo destro incluso: $$(-1,6]$$.
3. Ci sono due tratti distinti della retta reale: $$( -\infty,-3 ) \cup [4,+\infty)$$.
:::

### Esercizio 2
Scrivere in forma di disuguaglianza:

1. $$(3,9)$$
2. $$( -\infty,5 ]$$
3. $$[ -4,1 )\cup(1,+\infty)$$

:::{dropdown} Svolgimento
1. $$(3,9)$$ corrisponde a $$3<x<9$$.
2. $$( -\infty,5 ]$$ corrisponde a $$x \leq 5$$.
3. $$[ -4,1 )\cup(1,+\infty)$$ corrisponde a $$x \geq -4$$ e $$x \neq 1$$. Se si vuole mantenere la struttura completa: $$-4 \leq x < 1 \lor x > 1$$.
:::
